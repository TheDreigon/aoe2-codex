# aoe2-codex
A historical rework of the Age of Empires II civilizations and tech tree, shown in your web browser.

This is a fan project built on top of [aoe2techtree](https://github.com/SiegeEngineers/aoe2techtree)
(the code behind [aoe2techtree.net](https://aoe2techtree.net)), a project by [Siege Engineers](https://siegeengineers.org).
aoe2-codex is an independent fork: the aoe2techtree authors are not involved in it and have not reviewed or endorsed it.
The original game data is kept as it is; the reworked civilizations, the design rules and our own history texts live in
[`codex/`](codex/). Start with the project rules in [`codex/RULES.md`](codex/RULES.md).

The site's historical mode is in [`historical/`](historical/); the original aoe2techtree pages stay at the root,
in [`ror/`](ror/) and in [`chronicles/`](chronicles/).

## What comes from aoe2techtree and what is new

Everything that came from aoe2techtree is credited below ([Authors](#aoe2techtree)) and stays under its
[MIT License](LICENSE). Everything else is new material of the codex. The game's own data, texts and icons, in
both, are Microsoft's, used under the Game Content Usage Rules (see the notice below the table).

| Path | Origin |
|---|---|
| `data/`, `img/` (except the `codex-` icons), `fonts/`, `scripts/`, `js/svg.min.js`, `js/techtree.js`, `style.css`, `LICENSE`, `.editorconfig` | aoe2techtree, unchanged |
| `index.html`, `ror/index.html`, `chronicles/index.html` | aoe2techtree. The codex made the footer links relative, so that they work under a GitHub Pages sub-path, and added a link to the historical mode |
| `js/main.js` | aoe2techtree. The codex made the image paths relative to the site root (`SITE_ROOT`), for the same reason |
| `README.md`, `.gitignore` | aoe2techtree's, rewritten (this file) or extended for the fork; `CNAME`, which pointed to aoe2techtree.net, is removed |
| `codex/` | New: the rules, the civ designs, the reviews and the tools. The Scenario Editor unit lists in `codex/tools/` are extracted from the game |
| `historical/` | New: the historical mode. Its `index.html` is adapted from aoe2techtree's `chronicles/index.html`; its `data/` is generated by `codex/tools/build_site.py` from aoe2techtree's `data/` and the codex designs; `codex.js`, `codex.css`, `compare.html` and `compare.js` are new |
| `img/Unit/codex-*.png`, `img/Tech/codex-ut-feudal.png` | New files, taken from the game's own icons or made from them |
| `.nojekyll` | New: lets GitHub Pages serve the files as they are |

## Development

To run the website locally, either open `index.html` in Firefox
or execute one of the following commands in this directory and
open [localhost:8000](http://localhost:8000) in any browser:

 - `php -S localhost:8000`
 - `python3 -m http.server`
 - `python2 -m SimpleHTTPServer`
